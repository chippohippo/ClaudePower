Auto-import — apply this config to OTD + RawAccel in one command
1. Click ⧉ Copy aim_config JSON (top right) — the config goes to your clipboard (file downloads are blocked in this sandbox).
2. Run: powershell -ExecutionPolicy Bypass -File "C:\Users\Chippo\Organized\Folders\GamingOptimizerPro\apply-aim-config.ps1" (add -DryRun to preview). The script reads the config straight from your clipboard — or from a file via -ConfigPath if you saved one — and keeps a copy of what it applied next to itself as last_applied_aim_config.json.
The script backs up RawAccel's settings.json, applies the curve live via RawAccel's own writer.exe, writes an OTD preset named AimTuner into your Presets folder (next to "bo6 method" and "OVERWATCH KING"), and applies it instantly through OpenTabletDriver.Console.exe — no restarts, no GUI. Folder locations (RawAccel D:\RawAccel, OTD D:\Pen portable, tablet Wacom DTC-141) are editable in the marked FOLDER SETUP block at the top of the script. Run from a normal PowerShell, not "Run as administrator" — OTD's live-apply pipe belongs to your user session and rejects elevated shells.

3. (optional) Game files too: close your games, then run powershell -ExecutionPolicy Bypass -File "C:\Users\Chippo\Organized\Folders\GamingOptimizerPro\apply-game-settings.ps1" with the same copied config. It auto-detects each game's config (paths verified on your machine — Apex settings.cfg + videoconfig, OW2 Settings_v0.ini on your relocated F: Documents, Rivals GameUserSettings.ini, newest Valorant account config, Holdfast per-SteamID inis), writes the tool's resolution + lowest video settings + sens/FOV where the game stores them client-side, and backs up every file first. If detection misses, each path is overridable in the GAME PATHS block at the top. Not scriptable anywhere: Rivals sens (server-side) and Valorant sens (cloud) — it prints those for hand entry. Supports -DryRun and -Games apex,ow2 to limit scope.
